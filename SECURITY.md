# Security

Report a vulnerability as a confidential issue: open [a new issue](https://gitlab.com/dunn.dev/tower/-/issues/new) and tick "confidential" before submitting. Leave your health URLs and account identifiers out of the report.

Only the latest tag is supported. tower has a single maintainer, so responses are best effort.

The security model is in the [README](README.md#security-model).
